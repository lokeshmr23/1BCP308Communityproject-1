# Field validation protocol — not yet executed

Status: **PENDING**. No schools, respondents, interviews, photos or learners are reported as visited.

1. Obtain institutional and school permission. Identify a special educator as the decision-maker. Use caregiver consent and learner assent where required; explain stopping without penalty.
2. Agree on age range, preferred language, communication modes, sensory preferences and one individualized task. Do not infer an ability or diagnosis from dataset records.
3. Review all Kannada text and distractors. Remove any irrelevant, confusing or distressing content. Offer non-visual alternatives to colour/shape/digit recognition.
4. Check the actual shared device, browser, keyboard/touch/switch access, contrast, volume and connectivity. Read-aloud is optional; verify installed voices.
5. Let an educator demonstrate a task. Observe an agreed short, untimed practice; offer breaks. Log only necessary non-identifying observations under school-approved handling.
6. Record task completion, number of prompts, first-try responses, retries, ease of exiting, fatigue and educator feedback. Explain that prompt counts are contextual—not clinical outcomes.
7. Compare like-for-like baseline/follow-up tasks only if approved. Report denominator, missing sessions, assistance, task changes and alternative explanations. Do not infer causal learning gains from a convenience pilot.
8. Store signed consent outside this public Git repository. Do not upload names, diagnoses, photos, audio or identifiable CSVs. Clear shared-browser records after each agreed session.
9. Handover, train the educator, record unresolved issues and agree on a review date.
